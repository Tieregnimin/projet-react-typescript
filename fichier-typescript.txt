✅ Version TypeScript corrigée et commentée

// Import de React nécessaire pour JSX
import React from 'react';

// Déclaration d'une interface pour typer les props
interface GreetingProps {
  name: string;
}

// Composant fonctionnel avec typage des props
const Greeting: React.FC<GreetingProps> = ({ name }) => {
  return <div>Bonjour, {name} !</div>;
};

// Export par défaut du composant
export default Greeting;

✅ Explication

interface GreetingProps : déclare que name est une string
React.FC : facultatif mais pratique pour typer un composant fonctionnel

On a corrigé la mauvaise syntaxe du => ; {

✅ Version TypeScript corrigée et commentée

import React, { Component } from 'react';
// Interface pour typer le state
interface CounterState {
  count: number;
}

// Si besoin, on peut aussi typer les props (ici pas de props)
class Counter extends Component<{}, CounterState> {
  // Initialisation du state
  state: CounterState = {
    count: 0,
  };

  // Méthode pour incrémenter le compteur
  increment = () => {
    this.setState({ count: this.state.count + 1 });
  };

  // Rendu JSX
  render() {
    return (
      <div>
        <p>Count : {this.state.count}</p>
        <button onClick={this.increment}>Increment</button>
      </div>
    );
  }
}

// Export du composant
export default Counter;

✅ Explication

CounterState : interface pour décrire la structure du state
Component<{}, CounterState> : props vides, state typé
Correction de la syntaxe JSX mal fermée (ex. : return + ())
Correction de exporter le compteur par défaut → export default Counter
